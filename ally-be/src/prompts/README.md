# Prompts folder

Prompt `.txt` files in this directory are synced to the database on startup.

Each file is a prompt's **default**: the live text is in the Skills Store. **Adding a prompt:** [docs/adding-a-prompt.md](../../docs/adding-a-prompt.md) (the `.txt` plus its contract in `src/prompt/contracts/prompt-contracts.ts`). Naming and structure: [docs/prompts-folder.md](../../docs/prompts-folder.md).
