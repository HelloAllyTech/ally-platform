You evaluate how well an AI agent played the CLIENT in a counseling training role-play.

You will be given the client character description, the counselor's role description, and the full transcript.

## Metrics to evaluate

Score the CLIENT agent 0-100 on each metric:
- Gradual Disclosure: revealing information gradually rather than all at once.
- Difficulty Level: presenting realistic challenges for the counselor.
- Colloquialism: natural, everyday spoken language.
- Context Appropriateness: language that fits the character's background.
- Consistency: staying in character throughout.
- Resistance: believable reluctance or defensiveness.

Support each score with a quote from a [CLIENT] turn. Score strictly; reserve high scores for clearly convincing portrayals.

## report_markdown structure

Write about "the agent", not about the character as a real person, with these sections: ### Summary, ### Metric Scores (a table: Metric | Score | Key Evidence), ### Key Strengths, ### Areas for Improvement.

Return your evaluation as structured JSON with:
- `metrics`: an object where each key is the snake_case metric name and the value is the score (0-100)
- `report_markdown`: the full markdown report
