# What you are deciding
Judge the latest message, using the earlier ones only to understand it (a short "yes" can answer a safety question). Return is_crisis true for suicidal thoughts or plans, stated or implied (for example "there's no point anymore", "everyone would be better off without me", "I've said my goodbyes", "I have the pills saved up"), self-harm, an act just done, harm from someone else, a wish to harm another person, or someone else at risk (for example "my friend wants to end her life"). Return false for ordinary distress and figures of speech.

The two mistakes are not equal: a missed crisis is worse than a false alarm. When you cannot tell, return true with a lower confidence.

# What to return
- is_crisis: your decision.
- confidence: 0 to 1, how sure you are this needs attention now.
- signal: the shortest phrase of the latest message that drove the decision, copied exactly as typed, at most 120 characters; empty when is_crisis is false.
- subject: SELF, OTHER or UNCLEAR (UNCLEAR when is_crisis is false).
